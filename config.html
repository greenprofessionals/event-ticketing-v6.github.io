3. Ticket Tiers

Add only the tiers used for this event. Each tier may use a fixed dollar amount or BY DONATION.

Maximum 12 tiers. Tier names are saved in UPPERCASE. A capacity of 0 means no separate tier limit.

4. Branding

Upload the organization/event logo and an optional background image. The logo is also used as the large faint watermark. Images must be PNG, JPG, or WebP and no larger than 3 MB.

5. Save Configuration

Save before previewing. Saving replaces the current event configuration for this Event ID and returns the event to Client Submitted if an approved design is changed.

6. Ticket Preview

The preview uses the same ticket renderer as real tickets. The QR and serial are samples and cannot be used for admission.

7. Review & Approval

Review each tier, price, color, logo, venue, date, time, and all ticket text. Approve only when the ticket is ready for production.
